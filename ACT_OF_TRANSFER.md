## 2. Что передается

Передающая сторона передает принимающей стороне результат работ в виде финальной развернутой версии веб-сайта, доступной по согласованному адресу.

Передаются:

1. Финальная опубликованная версия сайта для использования по согласованному назначению.
2. Доступ к административной панели сайта для управления новостями.
3. Возможность через административную панель создавать, редактировать, публиковать, скрывать и удалять новости.
4. Возможность редактировать только тот контент, который специально доступен для редактирования через административную панель.
5. Инструкция или устное/письменное объяснение порядка входа в административную панель и базового редактирования новостей.
